🔑 Chave de API necessária

Para rodar no Netlify você precisa de uma chave da Anthropic. É gratuito criar uma conta e a chave fica salva só no seu navegador.

→ Criar chave em console.anthropic.com ↗
1Acesse console.anthropic.com e crie conta gratuita
2Vá em Settings → API Keys → Create Key
3Cole a chave abaixo (começa com sk-ant-...)
❌ Chave inválida. Deve começar com sk-ant-
🔒 A chave fica salva apenas no localStorage do seu navegador. Nunca é enviada para outros servidores além da Anthropic.
